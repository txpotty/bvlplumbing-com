    Sump Pump Installation Cost in Bethesda, MD

    Price depends mostly on whether a pit already exists. Swapping a pump in an existing pit is the cheapest job, while a new pit means saw cutting, digging, gravel and a concrete patch, which roughly doubles the labor. Backups add cost. We list each option on a written quote.

    Sump Pump Replacement in Bethesda, MD

    Floats stick and motors seize when a pump sits idle for months between storms. We pull the old pump and inspect the pit. If the old one could not keep up, we size up. Testing is done with a full pit.

    Combination Sump Pump System Installation in Bethesda, MD

    Two pumps on one riser cover both kinds of failure, a dead motor and a dead outlet. The primary handles daily water. People with carpet downstairs buy these. We install them in homes where a flood would ruin flooring and drywall.

    Combination Sump Pump Systems in Bethesda

    Combination units pair a primary pump and a battery backup on one pre-plumbed discharge assembly. Because everything comes assembled on a single riser, they fit into an 18-inch pit that would be too tight for two separate pumps and two check valves. Install time is shorter too. We set them in homes that want two layers without a bigger pit.

    Battery Backup Sump Pump Installation in Bethesda, MD

    Storms knock out power at the exact moment the pit is filling fastest. The backup pump gets its own float and its own check valve, and it runs off a sealed 12-volt battery when the outlet goes dead. A good battery carries it through most outages. We mount the charger on the wall, off the floor.

    Submersible Sump Pump Installation in Bethesda

    Submersible pumps live at the bottom of the pit with a sealed, oil-cooled motor. They run quieter and move more water. Lids close flat over them. Each install gets a sealed lid and a grommet around the cord to keep out radon and odor.

    New Sump Pit Installation in Bethesda

    No pit yet? We cut one at the low corner. We backfill around the basin with washed gravel so groundwater has a path in. The slab gets patched with new concrete. The pump, lid and discharge go in last.

    Battery Backup Sump Pump Systems in Bethesda, MD

    Backup systems we install use sealed AGM batteries that do not need water. The charger keeps the battery topped off. Expect a battery swap every four to five years. Finished basements get the most out of them.
